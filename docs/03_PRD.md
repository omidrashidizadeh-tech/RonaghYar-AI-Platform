# Product Requirements Document

## هدف Sprint جاری
کاربر حساب بسازد، برند را تعریف کند، مدل AI را Auto یا Manual انتخاب کند، محتوا تولید کند و نتیجه را در تاریخچه ببیند.

## Acceptance Criteria
- API سلامت، ثبت‌نام، ورود، Brand و Generate فعال باشد.
- حداقل Groq و OpenAI مسیر اجرایی داشته باشند.
- Claude و Gemini Adapter مستقل داشته باشند.
- Auto routing و fallback فعال باشد.
- مصرف روزانه بر اساس پلن کنترل شود.
- خطای Provider به پیام قابل‌فهم تبدیل شود.
